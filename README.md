# Physics-constrained Finetuning of Aurora, EO Foundation Model, for Sea Surface Temperature Forecasting

Code repo for the course project of Group 1, ECE-8936/ENGI-9882/COMP-6936 course
---

**Overview:**
The project involves implementing and evaluating an advanced machine learning (ML) system. Students may work individually or in groups of up to three. Projects can align with personal research interests but cannot reuse previously completed work. The project must apply or adapt an *advanced ML method*, not simply use existing scikit-learn functions.

**Core Requirements:**

* Implement an ML system for a specific task.
* Explore advanced ML techniques discussed in class (or similar, with instructor approval).
* Compare against a baseline method in two aspects:

  1. **Statistical performance** (e.g., convergence iterations, accuracy).
  2. **Hardware performance** (e.g., throughput, runtime).

**Key Deadlines:**

* **Oct 9:** Enroll in a group on Brightspace (mandatory, even for solo work).
* **Oct 26:** Submit a one-page **project proposal** (5%).
* **Nov 23:** Submit **draft title, abstract, and short bio**.
* **Late Nov–Early Dec:** **In-class 10-minute presentation** (10%) + **feedback form** (5%).
* **Dec 7:** Submit **final report** (15%).

**Proposal Requirements:**

* Main body should be about one page, describing the planned project.
* Must include **at least one citation** from relevant ML literature.
* Include **preliminary or exploratory work** to show feasibility.
* Include a **short experiment plan per person** (≤0.5 page each):

  * Hypothesis.
  * Proxy statement (metrics to measure).
  * Protocol (how the experiment will be done).
  * Expected results.

**Final Report:**

* Minimum **four pages**, excluding references.
* Written in **ICML 2025 or IEEE conference format**, resembling a short workshop paper.
